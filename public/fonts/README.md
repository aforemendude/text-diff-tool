# Bundled fonts

TextDiffTool self-hosts the following variable WOFF2 fonts from Google Fonts. The application does not request font
stylesheets or font files from a CDN at runtime.

- Inter v20, normal style, weights 100–900
- JetBrains Mono v24, normal and italic styles, weights 100–800

Both families are licensed under the SIL Open Font License 1.1. Their copyright notices and complete license terms are
included in `inter/OFL.txt` and `jetbrains-mono/OFL.txt`.
